# 2026 삼성한우리합창단 정기총회 웹앱 (모듈형 프로젝트 구조)

유지보수와 수정이 빠르고 편리하도록 HTML 레이아웃, 스타일시트, 데이터(단원 명부·단칙·안건), 애플리케이션 로직을 분리한 폴더 구조입니다.

## 폴더 및 파일 구조
- `index.html` : 메인 화면 레이아웃 및 탭·모달 마크업
- `css/styles.css` : 커스텀 스타일 및 단상 프로젝터 확대 모드 스타일
- `js/data-members.js` : 2026 메리고잉 운영진(18명) 및 전체 인원 명부(134명) 데이터
- `js/data-config.js` : 삼성한우리합창단 단칙(제1조~제32조), 단칙 개정안(12건), 단장 선거 후보자, 정기총회 공식 식순 및 연간 행사 초기 데이터
- `js/app.js` : 화면 렌더링, 단칙 파일(`.docx`/`.txt`) 업로드 파서, 키워드·조항 검색, 투표 집계, 운영진 인증 및 모달 제어 로직
- `assets/` : 단장 선거 후보자 프로필 이미지 (`cand_1.jpg`, `cand_2.jpg`, `cand_3.jpg`)
