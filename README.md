# 2026 삼성한우리합창단 정기총회 웹앱 (모듈형 최적화 구조)

- `index.html` : 메인 화면 레이아웃 및 탭·모달 마크업
- `css/styles.css` : 커스텀 스타일 및 프로젝터 확대 모드
- `js/data-members.js` : 단원 명부(134명) 및 운영진(18인) 데이터
- `js/data-config.js` : 단칙 전문(제1조~제32조), 개정안(12건), 후보자 및 식순 데이터
- `js/utils.js` : 공통 헬퍼 함수, 가결 기준 계산, 이스케이프 및 하이라이트
- `js/render.js` : 화면 렌더링 함수 모음
- `js/handlers.js` : 사용자 이벤트, 로그인 인증, 파일 파서, 내보내기 핸들러
- `js/app.js` : 앱 진입점 및 초기화
